# Meridian v0.1.2 — Clean book covers

Removed the decorative vertical spine highlight from library book covers. Covers retain their existing sizing, rounded corners and shadows across themes.

Includes all v0.1.1 features and fixes. No database migration is required.

Windows packages are unsigned. macOS packages use ad-hoc signing and are not notarized. Installed-app upgrade and screen-reader acceptance remain manual checks.

Windows packaging now resolves the WebView2 loader from the locked dependency and bundles it beside the executable.
