# Meridian v0.1.3 — Meridian 95 theme

Adds **Meridian 95**, an optional retro theme in Settings > Appearance: silver beveled controls, navy selections, recessed white fields, a navy Windows caption with silver caption buttons, and an original pixel-grid sidebar logo with bitmap MERIDIAN lettering. Other themes and their logos are unchanged, and Automatic still follows the system light/dark setting.

The theme adapts palette and bevel conventions from SolidCraft 95 under its MIT license; the notice ships with the app at `licenses/solidcraft-95.txt`. No fonts are bundled. The theme uses local Tahoma or Segoe UI.

Includes all v0.1.2 features and fixes. No database migration is required.

Windows packages are unsigned. macOS packages use ad-hoc signing and are not notarized. Installed-app upgrade, screen-reader and macOS/Linux rendering acceptance for the new theme remain manual checks.
